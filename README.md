# 学問の教科書(Gakumon)

大学の学問ごとの入門教科書を、スマホでもPCでも読めるWebアプリ(PWA)にしたものです。
大学受験ロードマップのアプリ(Aqualium)と同じく、
「本棚 → 本(表紙・目次)→ 単元のページ」のつくりと、翡翠グリーンの配色にそろえています。

## できること

| 機能 | 内容 |
| --- | --- |
| 📚 本棚 | 21の学問の教科書。分野(人文・社会・理学・工学・情報・医療・生命・農・建築)でしぼりこみ、学部名で検索できます。 |
| 📖 単元のページ | 学習目標 → 要点 → 本文(表つき) → 重要用語 → 板書の例題 → 説明チェック → 練習問題 → 次に学ぶ科目 → 出典。 |
| ✅ 練習問題 | 4択。その場で正誤と解説を表示し、結果を記録します。 |
| 📝 確認テスト | 本ごとに、練習問題からランダムに10問。まちがえた単元へのリンクを表示します。 |
| 🔁 復習 | まちがえた問題だけを集めて解き直せます。正解するとリストから消えます。しおり・本ごとの進みぐあいも見られます。 |
| 🔎 検索 | 全冊の本文・用語から、ことばでさがせます。 |
| ⚙️ 設定 | 文字の大きさ(4段階)・ライト/ダーク・学習データの書き出し/読み込み/消去。 |
| 📶 オフライン | 一度開いたページは、電波がなくても読めます(HTTPSで公開したとき)。 |

## 公開のしかた(GitHub Pages)

1. GitHub のリポジトリで **Settings → Pages** を開きます。
2. 「Branch」で公開したいブランチと `/ (root)` を選んで保存します。
3. 数分後に `https://<ユーザー名>.github.io/gakumon/` で開けます。

手元で試すときは、このフォルダで `python3 -m http.server 8000` を実行し、
ブラウザで `http://localhost:8000` を開きます。

## 本を増やす・直す

1. `js/data/` に1冊1ファイルで書きます。書き方は [docs/data-format.md](docs/data-format.md) を見てください。
2. `node tools/validate.js` で、データの形をチェックします(問題0件になるまで直す)。
3. `node tools/build-index.js` で、`index.html` に本を登録し、キャッシュの版を更新します。

## ファイル構成

```
index.html            画面の入口
css/style.css         デザイン(スマホ対応・ダークモード・印刷対応)
js/books.js           本の登録口(GK.addBook)
js/data/*.js          本のデータ(1冊1ファイル)
js/app.js             画面表示・学習記録・テスト・検索
sw.js                 オフライン対応
tools/validate.js     データの検査
tools/build-index.js  本の登録とキャッシュ更新
docs/data-format.md   本のデータの書き方
```

## 情報の扱い・注意点

- 文章はすべてオリジナルです。特定の教科書の文章は使っていません。
- 条文・年号・統計などの事実には、各ページに出典を付けています。法律や統計は改正・更新されることがあるため、最新の情報は出典先で確認してください。
- 大学・学部によって、学ぶ内容や順番は異なります。この本は「入門の一例」です。
- 医療に関する内容は学問の入門としての一般的な説明であり、診断や治療の助言ではありません。
- 学習の記録は、その端末のブラウザ(localStorage)にだけ保存されます。ログイン機能はありません。
