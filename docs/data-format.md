# 本のデータの書き方(js/data/*.js)

1冊 = 1ファイル。`GK.addBook({...})` で本棚に追加します。
読み込みは `index.html` の `<script defer src="js/data/〇〇.js">` に1行足すだけです。

## 本(1冊)

```js
GK.addBook({
  id: 'law',                 // 半角英字(URLに使う。ほかの本と重ねない)
  name: '法学入門',           // 本の名前(表紙)
  short: '法学',              // 短い名前(上のバー・本棚)
  field: 'social',            // 分野:humanities(人文)/social(社会)/science(理学)/engineering(工学・情報)/life(医療・生命・農)/design(建築・芸術)
  color: '#1d6f8a',           // 表紙の色(濃いめ。白文字が読める色)
  motif: 'scale',             // 表紙の図柄:scale / book / graph / atom / flask / leaf / gear / heart / globe / brain / code / pen / building / sigma / people / coin
  faculty: ['法学部'],        // この学問を学べる主な学部(目安)
  about: 'この学問は何を…',    // この学問とは(2〜4文)
  fit: ['…が好き', '…'],      // 向いている人(3つ)
  careers: ['…', '…'],        // 生かせる進路の例(3〜5個。「例」として書く)
  chapters: [ { name: '章の名前', pages: [ ページ, ページ ] } ]
});
```

## ページ(1単元)

```js
{
  id: 'law-1-1',             // 本のid-章-番号
  title: '法とは何か',
  goal: ['…を説明できる', '…'],   // 学習目標(2〜3個。「〜できる」で終える)
  point: '一文〜二文の要点',
  secs: [                     // 本文(2〜4節)
    { t: '見出し', p: ['段落', '段落'] },
    { t: '見出し', list: ['箇条書き', '…'] },          // p と list はどちらか・両方でも可
    { t: '見出し', table: [['列1','列2'], ['a','b']] }  // 1行目が見出し行
  ],
  terms: [['用語', '説明'], …],          // 重要用語(3〜6個)
  ex: [ { q: '例題・ケース', steps: ['考え方1', '考え方2'], a: '答え' } ],   // 板書の例題(1〜2問)
  check: [ { q: '自分の言葉で説明してみよう', a: '解答例' } ],               // 説明チェック(2〜3問)
  quiz: [ { q: '問題文', c: ['選択肢A','B','C','D'], a: 0, e: '解説' } ],   // 練習問題(4〜5問。a は正解の番号 0始まり)
  papers: [ { t: '著者(年)「題名」掲載誌', p: 'どんな研究で、何がわかったか(2〜3文)', u: 'https://…' } ],  // 論文・研究から学ぶ(1〜2本)
  next: ['大学で続けて学ぶ科目名', '…'],  // 次に学ぶ科目(2〜4個)
  src: [ { t: '出典名', u: 'https://…' } ]  // 事実(数字・条文・年号など)の出典。なければ省略
}
```

## 文章のきまり

- 読み手は高校生〜大学1年生。専門用語は必ずかみくだいて説明する。
- `**太字**` と書くと強調になります(ほかの記号は使わない)。
- 数字・年号・条文・統計など「事実」は、確かなものだけを書き、`src` に出典を付ける。
- 学説が分かれる内容は「〜という考え方がある」「大学によって扱いが異なる」と書き、断定しない。
- 特定の教科書・本の文章を写さない(すべてオリジナルの文章)。
- 出典(src)と論文(papers)のURLは、`node tools/check-links.js js/data/〇〇.js` で実際に開けることを確かめる。
